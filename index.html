I am a data analytics and data engineering professional pursuing a Master of Science in Data Analytics and Data Engineering at Western Governors University, building on a Bachelor of Applied Science in Data Analytics and Artificial Intelligence from Broward College. Plain language: PCA looks for the handful of underlying patterns that explain most of the variation in the data, so you can work with fewer variables without losing much information. Here, 2 of 7 components were worth keeping.

ML Experiment Tracking Pipeline

Built a reproducible machine learning pipeline for flight delay prediction with versioned data using DVC, tracked experiments and metrics with MLflow, and automated testing and deployment through a GitLab CI/CD pipeline. Click each stage below to see what happens.

Pulls raw flight delay records for the chosen airport from the Bureau of Transportation Statistics and versions the raw file with DVC, so every run points at the exact same dataset, byte for byte.

Filters and cleans the raw records, handles missing values and outliers, and versions the cleaned dataset separately, so the entire transformation is fully reproducible.

Trains a flight delay prediction model on the cleaned data, saving the trained model as a versioned artifact ready for deployment.

MLflow records every run automatically, parameters, metrics, and artifacts, so past experiments always stay comparable. Below is a real run captured from this project.

Packages the trained model behind a FastAPI endpoint inside Docker, then tests and deploys it automatically through a GitLab CI/CD pipeline on every push.
